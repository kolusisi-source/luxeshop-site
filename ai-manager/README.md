# AI 總管智能體（AI Manager Agent）

一個專門**設計**與**監督**其他 AI 的總管。你只要給它一個目標，它會自己拆任務、為每個任務「設計」一個專職 AI、派工、逐條審查、退回重做，最後交出成果與完整稽核紀錄。

## 架構

```
             ┌──────────────────────────────┐
  目標 ───▶  │  AI 總管 (Manager)            │
             │  1. 規劃：拆子任務            │
             │  2. 設計：為每個任務產生       │
             │     角色 / 系統提示 / 驗收標準  │
             └──────────┬───────────────────┘
                        │ 依 depends_on 排序派工
        ┌───────────────┼───────────────┐
        ▼               ▼               ▼
   專職 AI #1       專職 AI #2       專職 AI #3   ← 由總管動態設計，不是寫死的
        │               │               │
        └──────▶ 總管審查（逐條驗收標準、0-10 評分、風險標記）
                        │
          ┌─────────────┼──────────────┐
       approve        revise         超過重試上限
          │      （附具體修改意見     │
          │        退回同一段對話）    ▼
          ▼                       needs_human（升級給人）
     彙整成果 + 稽核紀錄 runs/run-*.json
```

## 總管的五個職責

| 職責 | 做法 | 程式位置 |
|---|---|---|
| **規劃** | 把目標拆成 2-5 個界線清楚、可獨立驗收的子任務 | `plan()` |
| **設計 AI** | 每個子任務產生 `WorkerSpec`：角色、系統提示、任務、驗收標準、相依關係 | `WorkerSpec` |
| **監督** | 用結構化輸出（Pydantic）逐條檢查驗收標準，給分數、判決、修改意見、風險標記 | `review()` |
| **修正迴圈** | 不合格就把意見接在同一段對話後面，讓專職 AI 在原有脈絡上修改 | `supervise()` |
| **升級與稽核** | 超過 `MAX_REVISIONS` 仍不合格 → 標記 `needs_human`；所有產出與評審存成 JSON | `main()` |

## 設計重點

- **專職 AI 是「被設計」出來的**：總管依目標即時產生系統提示，不需要事先寫好每一種 AI。
- **結構化輸出**：規劃與審查都用 `client.messages.parse` + Pydantic schema，保證格式正確、可以程式化判斷。
- **審查者與執行者分離**：審查在獨立的對話中進行，只看產出與標準，避免自己改自己的作業。
- **雙重門檻**：必須 `verdict == approve` **且** `score >= PASS_SCORE` 才通過。
- **相依關係**：後面的 AI 可以拿到前面已通過的成果當參考（例如 SEO AI 讀文案 AI 的成果）。
- **安全**：專職 AI 開啟伺服器端 refusal fallback；遇到拒絕會明確報錯，不會默默當成功。
- **人在迴路中**：有 `needs_human` 時程式以 exit code 2 結束，方便接到 CI 或排程中提醒人工檢查。

## 使用方式

```bash
cd ai-manager
pip install -r requirements.txt
export ANTHROPIC_API_KEY=你的金鑰

python manager.py "為 LuxeShop 撰寫三款精品手錶的商品文案、SEO 標題與 Instagram 貼文"
```

可調參數（`manager.py` 開頭）：

| 參數 | 預設 | 說明 |
|---|---|---|
| `MANAGER_MODEL` | `claude-opus-5-5` | 總管使用的模型 |
| `WORKER_MODEL` | `claude-opus-5-5` | 專職 AI 使用的模型（想省成本可改成 `claude-sonnet-5-5`） |
| `MAX_REVISIONS` | `2` | 每個任務最多退回幾次 |
| `PASS_SCORE` | `8` | 合格分數（0-10） |

## 可以延伸的方向

1. **給專職 AI 工具**：例如讀寫網站檔案、查商品資料庫、網路搜尋（Claude API tool use）。
2. **平行執行**：沒有相依關係的子任務可以同時跑。
3. **長期記憶**：把過去被退回的原因存起來，下一次設計系統提示時自動避開。
4. **排程**：每天自動檢查網站內容、產生新文案並送審。
5. **人工審核介面**：把 `runs/*.json` 做成網頁儀表板，讓人一鍵核准或退回。
